# AmbientWill

AmbientWill is a local-first proactive cognition and messaging layer for
persistent AI agents.

The current v0.1 work is an offline shadow simulator. It can evaluate whether a
candidate wake-up should sleep, reflect, or plan a message, but it cannot send
real messages and does not connect to Hermes, an LLM, or the network.

See [the Chinese PRD](docs/PRD.zh-CN.md) for the product direction and safety
boundaries.
